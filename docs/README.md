# Friday User Guide

Friday is a simple chatbot that helps you manage your tasks.

## Quick Start

1. Make sure Java is installed.
2. Start Friday.
3. Type a command and press Enter.
4. Type `bye` to exit.

## Features

### View all tasks
Use `list` to show all tasks.

### Add a todo
Use `todo <description>`

Example: `todo read book`

### Add a deadline
Use `deadline <description> /by <date>`

Example: `deadline submit report /by Friday`

### Add an event
Use `event <description> /from <start> /to <end>`

Example: `event project meeting /from 2pm /to 4pm`

### Mark a task as done
Use `mark <task number>`

Example: `mark 2`

### Unmark a task
Use `unmark <task number>`

Example: `unmark 2`

### Delete a task
Use `delete <task number>`

Example: `delete 3`

### Find tasks by keyword
Use `find <keyword>`

Example: `find report`
